C1 · As it wasFour tiles, then the rules, versions and templates in cards

The variant you picked, unchanged, to compare the others against.

C2 · The weekThe hours tile becomes a week strip

The widest tile draws the week: a bar per day with the hours AiMY covers filled in, so "weekends all day" is seen rather than read. Urgent and not urgent share one card, split down the middle, and urgent words are in the error colour.

C3 · Dial and timelineThe Schedule page's clock, and versions as a line

The hours tile carries the Schedule page's clock itself: the 24-hour ring with the moon and sun, so the two pages say it the same way. The manager tile has the person. Versions run left to right as a timeline with the live one filled.

C3 with four files · CardsA product with up to four config files, each saying when it applies

The GitHub Actions way: every file says when it applies, like a workflow's on:. AiMY checks them in order and reads the first that fits the ticket; the default fits everything and is always last. The files sit as a row of cards in that order, and the chosen one (Weekends here) fills C3 below. A line at the top says which file AiMY reads right now.

C3 with four files · ListThe same four, as an ordered list beside the chosen file

The order is the rule, so the list shows it top to bottom, with Move up on each file except the default. It keeps the file name, its condition and its place together, and leaves the full width under the header to C3.

C3 with four files · DropdownThe file name is the switcher

Your idea: the file's name in the header opens the four files, in the order AiMY checks them, with the condition under each. It is shown open here; press the name to close it, or pick a file. The files named in the "Right now" line switch too, so the menu is not the only way to reach one. Nothing else on the page moves, so C3 keeps the full width.

C4 · One stat barLighter: one bar for the four facts, then plain rows

The four tiles become one bar split in four, the rules are rows of chips without a card around them, and versions and templates are two plain lists side by side. The fewest boxes of the four.
